## 📖 项目简介

**东方养生·华烨尚医** (v2.1.0) 是一款融合传统中医智慧与现代电商体验的养生手串定制小程序。通过科学的体质测试，为用户精准推荐专属的养生手串，并提供完善的会员积分体系，实现个性化的健康管理方案。

### 🎯 核心理念

- **中医体质辨识** - 基于王琦院士九种体质理论，科学识别用户体质特征
- **个性化定制** - 根据体质推荐专属配方，支持材质、尺寸、刻字定制
- **会员等级体系** - 白银/黄金/钻石三级会员，享受专属权益
- **积分生态系统** - 消费返积分、签到得积分、邀请好友赠送积分
- **东方美学设计** - 元古风格 UI，水墨书法字体，传承东方韵味

### 🌟 v2.1.0 新特性

> **会员积分体系重磅上线**

| 新功能 | 说明 |
|--------|------|
| 会员等级系统 | 白银(¥500)、黄金(¥2000)、钻石(¥5000) 三级体系 |

## 💰 积分系统

### 积分比例

| 积分类型 | 获取方式 | 基础积分 | 说明 |
|----------|----------|----------|------|
| 🛒 **消费积分** | 购物消费 | 20/元 | 实际支付金额，不含运费 |
| 📅 **签到积分** | 每日签到 | +1/天 | 连续签到7天额外+5 |
| ⭐ **评价积分** | 商品评价 | +10/条 | 带图评价额外+20 |
| 👥 **邀请积分** | 邀请好友 | +50/人 | 好友完成首单后发放 |

### 积分获取示例

```
场景1：购买 ¥500 手串（白银会员）
  - 消费积分：500 × 20 × 1.2 = 12,000 积分

场景2：购买 ¥2000 手串（黄金会员）
  - 消费积分：2000 × 20 × 1.5 = 60,000 积分

场景3：钻石会员购买 ¥5000 定制手串
  - 消费积分：5000 × 20 × 2.0 = 200,000 积分
```

### 积分规则详情

#### 每日签到
- 每次签到：+1 积分
- 连续签到 7 天：额外 +5 积分
- 中断签到：连续天数重置

#### 商品评价
- 文字评价：+10 积分
- 带图评价：+30 积分（含基础10 + 图片20）
- 每商品仅首评有效

#### 邀请好友
- 获得好友微信号/手机号
- 好友完成首单后：+50 积分
- 邀请无上限

### 积分使用

积分可用于：
- 🔄 积分兑换商品
- 🎫 积分抵扣订单（比例待定）
- 🎁 积分商城专属礼品

## 🚀 快速开始

### 环境要求

| 工具 | 版本要求 | 说明 |
|------|---------|------|
| Node.js | >= 18.x | 运行环境 |
| pnpm | >= 9.0.0 | 包管理器 |
| 微信开发者工具 | 最新版 | 小程序开发调试 |

### 克隆项目

```bash
git clone https://github.com/DaZhang/aura-care.git
cd aura-care
```

### 安装依赖

```bash
pnpm install
```

### 开发模式

```bash
# 启动完整开发环境（H5 + 后端，支持热更新）
coze dev

# 或分别启动各端
pnpm dev:web      # H5 开发服务器 (端口 5000)
pnpm dev:server   # 后端 API 服务 (端口 3000)
pnpm dev:weapp    # 微信小程序开发（需配合开发者工具）
```

### 验证代码质量

```bash
# 运行代码检查和类型检查
pnpm validate
```

### 构建生产版本

```bash
# 构建所有平台
pnpm build

# 单独构建
pnpm build:web      # 构建 H5
pnpm build:weapp    # 构建微信小程序
pnpm build:server   # 构建后端服务
```


| POST | `/api/user/points/signin` | 签到获取积分 |
| POST | `/api/user/points/consume` | 消费获取积分 |
| POST | `/api/user/points/review` | 评价获取积分 |
| POST | `/api/user/points/invite` | 邀请获取积分 |
| GET | `/api/user/member` | 获取会员等级信息 |
| GET | `/api/user/stats` | 获取用户统计数据 |

### 代码规范

- **ESLint** - 代码质量检查（`pnpm lint:build`）
- **TypeScript** - 强类型约束（`pnpm tsc`）
- **Tailwind CSS** - 原子化样式优先
- **pnpm validate** - 提交前必须通过所有检查
