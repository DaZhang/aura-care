# 功能文档

## 功能概览

东方养生·华烨尚医小程序包含以下核心功能模块：

---

## 1. 首页模块

### 1.1 顶部导航
- **品牌展示** - 显示"东方养生·华烨尚医"品牌名称
- **搜索入口** - 点击跳转搜索页面
- **体质测试快捷入口** - Sparkles 图标，快速进入体质测试

### 1.2 活动入口
| 活动 | 功能 |
|------|------|
| 新人专享 | 显示新人优惠弹窗，首单立减50元 |
| 限时特惠 | 显示限时活动弹窗，精选手串8折起 |
| 体质测试 | 跳转到体质测试页面 |

### 1.3 九大体质入口
- 展示九种体质类型图标
- 点击跳转对应体质的商品详情页
- 体质列表：平和质、气虚质、阳虚质、阴虚质、痰湿质、湿热质、血瘀质、气郁质、特禀质

### 1.4 体质测试卡片
- 渐变背景卡片设计
- 点击进入体质测试流程

### 1.5 个性化定制入口
- 展示定制功能说明
- 点击跳转定制页面

### 1.6 推荐商品
- 商品网格展示
- 显示商品图片、名称、价格、销量
- 点击跳转商品详情页

---

## 2. 搜索模块

### 2.1 搜索功能
- **关键词搜索** - 输入关键词搜索商品、体质、香料
- **搜索历史** - 本地存储最近10条搜索记录
- **热门搜索** - 展示热门搜索词，含热门标记

### 2.2 搜索结果
**商品结果**
- 商品图片、名称、价格、销量
- 点击跳转商品详情

**体质结果**
- 体质名称、描述、颜色标签
- 点击跳转对应商品

**香料结果**
- 香料名称、功效、对应体质
- 点击跳转定制页面

### 2.3 搜索提示
- 输入体质名称查看相关商品
- 输入香料名称了解功效
- 输入商品关键词直接购买

---

## 3. 体质测试模块

### 3.1 测试流程
1. 进入测试页面，显示进度条
2. 回答10道体质测试题目
3. 每题4个选项，选择后自动进入下一题
4. 完成后自动计算体质类型
5. 显示测试结果概览

### 3.2 测试结果页
- **体质名称** - 显示识别出的体质类型
- **体质特征** - 展示该体质的主要特征标签
- **专属配方** - 推荐的香料组合及功效说明
- **调理建议** - 日常调理建议列表
- **操作按钮** - 立即定制手串 / 查看推荐商品

### 3.3 九大体质详情

| 体质 | 特征 | 推荐香料 |
|------|------|----------|
| 平和质 | 阴阳调和，精力充沛 | 檀香+沉香+薰衣草 |
| 气虚质 | 易疲乏，气短自汗 | 黄芪+人参+白术 |
| 阳虚质 | 畏寒怕冷，手足不温 | 肉桂+干姜+杜仲 |
| 阴虚质 | 口燥咽干，手足心热 | 麦冬+石斛+百合 |
| 痰湿质 | 形体肥胖，腹部肥满 | 陈皮+茯苓+苍术 |
| 湿热质 | 面垢油光，易生痤疮 | 藿香+佩兰+荷叶 |
| 血瘀质 | 肤色晦暗，易有瘀斑 | 丹参+红花+川芎 |
| 气郁质 | 情绪低落，易焦虑 | 玫瑰+合欢花+佛手 |
| 特禀质 | 易过敏，有遗传倾向 | 黄芪+防风+甘草 |

## 4. 商品详情模块

- 商品图片轮播展示
- 商品名称、价格、原价
- 体质标签、销量、评分

### 4.2 香料配方

- 辅助香料介绍

- 显示材质价格差异

- 可定制刻字

- 用户头像、昵称
- 评价内容、评分、日期

### 4.6 操作按钮
| 按钮 | 功能 |
|------|------|
| 立即购买 | 跳转订单确认页面 |
| 立即定制 | 跳转定制页面 |

## 5. 定制模块

### 5.1 手串预览
- 实时预览手串效果
- 根据选择的材质联动变化

### 5.2 配方选择
- 根据体质推荐香料配方
- 显示每种香料的功效说明

### 5.3 材质选择
| 材质 | 价格 | 说明 |
|------|------|------|
| 檀香木 | 基础价 | 深褐色，经典选择 |
| 玉石 | +80元 | 翠绿色，温润通透 |
| 水晶 | +100元 | 透明，纯净能量 |
| 沉香木 | +120元 | 黑褐色，珍贵木种 |

### 5.4 刻字服务
- 最多6个字
- 加收20元
- 刻在吊牌上

### 5.5 数量选择
- 步进器选择数量
- 实时计算总价

### 5.6 价格计算
```
总价 = (基础价 + 材质差价 + 刻字费) × 数量
```

### 5.7 提交订单
- 点击"立即定制"跳转订单确认页

## 7. 支付模块

### 7.1 支付流程
1. 订单确认页提交订单
2. 调用支付接口
3. 模拟支付成功
4. 更新订单状态为"已支付"

### 7.2 支付接口
```
POST /api/order/pay
{
  "orderId": "订单ID",
  "payMethod": "wechat"
}
```

## 10. 后端 API 接口

### 10.1 体质相关
```
GET  /api/constitution/types        # 获取体质类型列表
GET  /api/constitution/questions    # 获取测试题目
POST /api/constitution/submit-test  # 提交测试结果
GET  /api/constitution/detail/:type # 获取体质详情
```

### 10.2 商品相关
```
GET  /api/product/list              # 获取商品列表
GET  /api/product/detail/:id        # 获取商品详情
GET  /api/product/spices            # 获取香料列表
GET  /api/product/materials         # 获取材质列表
GET  /api/product/calculate-price   # 计算定制价格
GET  /api/product/search            # 搜索商品/体质/香料
```

### 10.3 订单相关
```
POST /api/order/create              # 创建订单
GET  /api/order/list                # 获取订单列表
GET  /api/order/detail/:id          # 获取订单详情
POST /api/order/update-status       # 更新订单状态
POST /api/order/pay                 # 订单支付
```

### 10.4 存储相关
```
POST /api/storage/upload-image      # 上传图片
GET  /api/storage/image-urls        # 获取图片URL列表
```

## 11. 数据结构

### 11.1 商品数据
```typescript
interface Product {
  id: string
  name: string
  price: number
  originalPrice: number
  images: string[]
  constitution: string
  constitutionColor: string
  constitutionBg: string
  description: string
  spiceInfo: SpiceInfo[]
  features: string[]
  material: string[]
  sales: number
  rating: number
  reviews: Review[]
}
```

### 11.2 订单数据
```typescript
interface Order {
  id: string
  userId: string
  products: OrderProduct[]
  totalAmount: number
  status: OrderStatus
  address: Address
  createTime: string
  payTime?: string
}

type OrderStatus = 'pending' | 'paid' | 'shipped' | 'completed' | 'cancelled'
```
